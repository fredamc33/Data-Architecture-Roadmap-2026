❌ ESTRUCTURA INEFICIENTE (Muchos archivos pequeños / Sin particionar)
s3://my-bucket/logs/file_0001.json  (10 KB)
s3://my-bucket/logs/file_0002.json  (12 KB) ... [100,000 archivos]
└─> Resultado: Alto costo de API S3, consultas lentas y escaneo del 100% de datos.


✅ ESTRUCTURA OPTIMIZADA (Particionada / Formato Parquet / Archivos Grandes)
s3://my-bucket/logs/year=2026/month=09/day=25/
   ├── data_block_01.snappy.parquet  (256 MB)
   └── data_block_02.snappy.parquet  (256 MB)
                                   │
                                   ▼
          QUERY: SELECT * FROM logs WHERE year='2026' AND month='09';
          └─> Partition Pruning: Ignora todos los demás años/meses.
          └─> Ejecuta `MSCK REPAIR TABLE logs;` si se añaden particiones manualmente en S3.
